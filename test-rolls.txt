## How to Test

### Download Test
1. Navigate to the app
2. Go to the 2-str prediction tab
3. Enter some rolls manually
4. Click "Download Translated Rolls"
5. Verify the file contains rolls in chronological order

### Import Test
1. Save this file as `test-rolls.txt`
2. Navigate to the 2-str prediction tab
3. Click "Import Rolls"
4. Select this file
5. Verify rolls appear in the same order

### Backtest Test
1. Enable debug mode: add `?debug=true` to URL
2. Create a session with predictions
3. Export the debug logs
4. Navigate to Debug Panel → Backtest tab
5. Import the exported file
6. View the comparison results

## Expected Results

### Download
- File should contain only translated rolls (41-44 format)
- Order should be chronological (oldest first)
- No duplicates unless actually entered twice

### Import
- Rolls should be added in file order
- Should preserve chronological sequence
- Should work with both session and imported rolls

### Backtest
- Should show original predictions
- Should show current predictor results
- Should highlight improvements (📈) and regressions (📉)
- Should show accuracy metrics for both versions
