# Svarog Alerts Masterclass

## What This Guide Explains

This guide is for explaining the **live alert messages** in Svarog Tracer.

It covers:

- what the **lane** is
- what the **main lane** means
- what the **Main Predictor** does
- what the **Svarog Eye / Svarog Analyzer** does
- what the warning messages mean
- how a user should actually read the card

This is the version you can speak from in a video.

---

## The First Thing To Understand

Live Mode now has **two different jobs** on the same card:

1. **Main Predictor**
2. **Svarog Eye / Svarog Analyzer**

They are connected, but they are not the same thing.

---

## What Is The Lane

The **lane** is the **2-line path** the session is most likely living on right now.

Example:

- the card shows `42 / 43`

That means:

- the safest current path is line 2 or line 3

That is the lane.

So when I say:

- **lane**
- **main lane**
- **trusted pair**

I mean the same core idea:

- the 2-line path the system thinks is safest to trust right now

---

## What Is The Main Lane

The **main lane** is simply the lane chosen by the **Main Predictor**.

If the card says:

- `Your 2 Picks This Session`
- `42` or `43`

Then:

- `42 / 43` is the main lane

This is the safer read.

It does **not** mean:

- “42 must be next”

It means:

- “the session currently looks like it belongs inside the 42/43 pair”

---

## What The Main Predictor Does

The Main Predictor is not trying to be a perfect exact-roll oracle.

Its real job is:

- identify the safest 2-line lane
- detect how stable that lane is
- warn when the lane is at risk of breaking

So the Main Predictor is your:

- **pair guide**
- **safety guide**
- **lane guide**

That is why the main card shows:

- pair
- safety
- noise risk
- break pressure

---

## What Svarog Eye Means

The **Svarog Eye** is the exact-pick layer.

Its job is:

- predict the next exact line more aggressively
- react to breaks and shifts faster
- give a sharper but riskier next-line lean

So if Main Predictor says:

- `42 / 43`

and Svarog Eye says:

- `[41] [42]`

that means:

- the safe lane is still `42 / 43`
- but the exact sharper guess is leaning `41`, then `42`

---

## The Difference In One Sentence

This is the best one-line explanation:

> Main Predictor tells you the safest 2-line lane. Svarog Eye tells you the sharper next exact line.

That sentence explains almost the whole system.

---

## Reading The Safety Banner

At the top of the card, you now see a safety banner.

Example:

- `Break Danger`
- `42 / 43 • mixed window`
- `Noise Risk 60%`
- `Break pressure: 41`

This area answers one question:

> How safe is the current lane right now?

---

## What The Safety Labels Mean

### Trusted Pair

This means:

- the lane is stable enough to trust
- session is mostly behaving inside that 2-line pair

User meaning:

- you can follow the pair with more confidence

### Pair At Risk

This means:

- the lane still exists
- but it is no longer fully stable

User meaning:

- you can still use the lane
- but you should be watching for a break

### Break Danger

This means:

- the lane is fragile
- a break is actively threatening it

User meaning:

- do not treat the pair as fully safe
- this is where Svarog Eye matters more

---

## What Noise Risk Means

**Noise Risk** tells you how dangerous the pair is.

It is not:

- “how good the pair is”

It is:

- “how likely the pair is to fail”

Simple reading:

- `0-25%` = pretty safe
- `26-45%` = caution
- `46%+` = real danger

So if you see:

- `Noise Risk 60%`

that means:

- the lane is fragile
- an outsider can break it

High noise risk = dangerous.  
Low noise risk = safer.

---

## What Break Pressure Means

**Break pressure** shows the value most likely to break the lane.

Example:

- `Break pressure: 41`

That means:

- 41 is the outsider currently pushing hardest against the lane

So if the lane is:

- `42 / 43`

and break pressure is:

- `41`

that means:

- 41 is the most dangerous off-lane value right now

---

## What Mixed Window Means

If the banner says:

- `mixed window`

that means:

- the session is not cleanly stable
- more than two values are active
- transitions are happening faster

User meaning:

- the lane is weaker
- noise risk matters more
- Svarog Eye can become more valuable than usual

If it says:

- `stable lane`

that means:

- the session is behaving more consistently
- the pair is more trustworthy

---

## What “Lean Here” Means

Under the two picks, the card highlights one side as:

- `Lean Here`

That means:

- inside the main lane, that value currently has the better lean

So if the lane is:

- `42 / 43`

and `42` says:

- `Lean Here`

that means:

- the safer lane is still `42 / 43`
- but within that lane, `42` is the stronger side right now

---

## What The Svarog Eye Boxes Mean

Example:

- `Svarog Eye`
- `[41] [42]`

This means:

- `41` is the sharper exact next-line guess
- `42` is the backup exact candidate

This is **not** the lane.

This is the **exact-roll layer**.

That is why the card says:

- `Svarog Analyzer - Next exact line`

because this part is trying to answer:

> If I had to guess the next exact hit, what do I pick?

---

## What The Svarog Message Means

Under the Svarog boxes, you now see a guidance message.

That message tells the user:

- should I trust the Main Predictor more?
- should I trust Svarog more?
- or are both saying the same thing?

These are the four important states.

---

## 1. Both Agree

Message:

- `Both agree`

Meaning:

- Main Predictor and Svarog are pointing to the same side

This is the strongest signal on the card.

User meaning:

- this is your best confirmation

If both systems agree, confidence is much better.

---

## 2. Follow Main Predictor

Message:

- `Follow Main Predictor`

Meaning:

- the lane is safe enough
- the pair should be trusted first

User meaning:

- follow the main lane
- use Svarog only as a small exact lean

This is the “play safe” state.

---

## 3. Check Svarog Analyzer

Message:

- `Check Svarog Analyzer`

Meaning:

- the pair is fragile
- the lane is still useful, but it may break
- the exact sharper break guess matters more now

User meaning:

- don’t blindly trust the pair
- pay attention to Svarog for the exact break call

This is the “pair is shaky, exact read matters more” state.

---

## 4. Split Read

Message:

- `Split Read`

Meaning:

- Main Predictor and Svarog are not aligned

User meaning:

- Main Predictor = safer lane
- Svarog = riskier exact next-line lean

This is the “you choose safety vs precision” state.

---

## What The Watch Message Means

At the bottom, you may see something like:

- `Watch: 41 may break the pair`

That means:

- 41 is the outsider most likely to break the current lane

This message is simple on purpose.

It is there to tell the user:

- “be careful, this value can jump in”

It does not mean:

- “41 is guaranteed next”

It means:

- “41 is the main danger to the current lane”

---

## Full Example From The Screenshot

Let’s read this exact kind of card:

- `Break Danger`
- `42 / 43 • mixed window`
- `Noise Risk 60%`
- `Break pressure: 41`
- main lane picks: `42 / 43`
- `Svarog Eye: [41] [42]`
- message: `Check Svarog Analyzer`
- watch: `41 may break the pair`

What does that really mean?

### Main Predictor is saying:

- the safest lane is still `42 / 43`

### But the banner is saying:

- this lane is fragile
- break risk is real

### Break pressure is saying:

- 41 is the outsider pushing hardest

### Svarog is saying:

- if I had to guess the exact next line, I would lean `41`, then `42`

### So the real read is:

- safe pair = `42 / 43`
- but the pair is not trustworthy enough to follow blindly
- 41 is the main danger
- Svarog is warning that the sharper exact break may be 41

That is why the message says:

- `Check Svarog Analyzer`

Because this is not a clean safe-lane situation anymore.

---

## How A User Should Decide What To Follow

### If Pair Safety is Safe

Usually:

- trust the main lane first

That means:

- follow the pair
- use Svarog only as an exact lean

### If Pair Safety is Caution

Usually:

- main lane still matters
- but start respecting break pressure more

### If Pair Safety is Danger

Usually:

- the lane is fragile
- this is where Svarog becomes much more important

### If Both Agree

That is the strongest read.

### If They Disagree

Use this simple rule:

- Main Predictor = safer
- Svarog Eye = sharper

If you want to explain it fast, say:

> The Main Predictor tells me the safest 2-line lane. The Svarog Eye tells me the sharper exact next line. If the lane is in danger, I look at Svarog more. If both agree, that is my strongest signal.

## Short Cheat Sheet

- **Lane** = trusted 2-line path
- **Main lane** = the pair chosen by the Main Predictor
- **Main Predictor** = safer pair guide
- **Svarog Eye** = sharper exact next-line guide
- **Trusted Pair** = lane is stable
- **Pair At Risk** = lane still usable, but weaker
- **Break Danger** = lane fragile, break active
- **Noise Risk high** = dangerous pair
- **Break Pressure** = outsider trying to break the lane
- **Both Agree** = strongest signal
- **Follow Main Predictor** = trust the lane first
- **Check Svarog Analyzer** = exact break guess matters more
- **Split Read** = lane safer, Svarog sharper
